# Contributing Guidelines

## Branching Strategy
- Create a **feature branch** from the **development branch when starting work on a new feature.
- When working on bug fixes, create a **bigfix branch** from **development**

## Commit Messages
- Use clear, descriptive commit messages.
- Follow the style: `Verb in present tense (e.g., 'fix bug', 'Add feature')`.

## Pull Request Process
- Submit all changees via **pull requests**.
- Ensure your branch is up-to-date with **development** before creating a pull request.
- Assign at least one reviewer for the pull request.
- Make sure your pull request passes all tests and CI checks before submitting.
